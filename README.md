# Radar Festivals Europe

Application web locale pour piloter ta prospection de festivals alternatifs et conscients en Europe.

## Fonctions incluses

- base initiale de festivals pre-remplie
- pipeline commercial par statut (a contacter, relances, calls, negociation, deal)
- filtres par pays, budget et statut
- edition, suppression et ajout de festivals
- sauvegarde automatique dans le navigateur (localStorage)
- export CSV pour travailler dans Excel ou Google Sheets
- calendrier de mise a jour 5 fois par an

## Utilisation

1. Ouvrir index.html dans ton navigateur.
2. Ajouter ou modifier les fiches festivals.
3. Cliquer sur Exporter CSV pour sortir un fichier de suivi.

## Donnees

Les donnees sont stockees en local dans la cle localStorage: festival-crm-v1.
Tu peux recharger la base de depart avec le bouton Recharger la base.
